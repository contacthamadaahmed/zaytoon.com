updated# ZAYTOON — النسخة التصميمية الثانية

موقع تعريفي خفيف باللغة العربية واتجاه RTL، متجاوب مع الهاتف والكمبيوتر، والطلبات عبر واتساب.

## التشغيل
افتح `index.html` في متصفح حديث مع اتصال بالإنترنت لتحميل خط Cairo وصور Unsplash. أو شغّل:
`python -m http.server 8000`
ثم افتح `http://localhost:8000`.

## تعديل السعر
في `app.js` غيّر:
`price: "250 جنيه"`
إلى السعر الحقيقي مثل:
`price: "٢٥٠ جنيه"`

## قبل النشر التجاري
- الصور الحالية صور تحريرية توضيحية من Unsplash وليست صورة عبوة ZAYTOON الأصلية؛ استبدلها بصورة المنتج الفعلية.
- أكد بيانات المنشأ والمواصفات.
- ادعاء انخفاض الحموضة يفضل دعمه بتحليل معملي منشور؛ لا تعرض نسبة رقمية غير موثقة.
- أضف السعر وتفاصيل التوصيل وسياسة الاستبدال.

## النشر
يمكن نشر الملفات على Vercel أو Netlify كـ Static Site. لا توجد قاعدة بيانات أو أسرار أو إعدادات خادم مطلوبة لهذه النسخة. لم يتم رفعها إلى حساب استضافة لأن ذلك يتطلب تسجيل دخول/صلاحية من مالك الحساب.

## تحديثات المراجعة
- تم فصل صورة الهيرو عن صورة بطاقة المنتج باستخدام صورتين تحريريتين موجودتين بالفعل.
- تم استبدال بطاقة الحموضة غير المدعومة بمعلومة حجم العبوة، مع الإبقاء على تنبيه التحليل المعملي.
- تم تحسين أيقونة واتساب العائمة وإمكانية الوصول، وضبط عزل اتجاه الأرقام والنصوص الإنجليزية.
